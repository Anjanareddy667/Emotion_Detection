Workflow Description
User Input – The user enters text through the Streamlit interface.
Text Processing – The input is prepared for feature extraction.
Feature Extraction – CountVectorizer converts the text into numerical features.
Model Inference – The numerical representation is passed to the trained classifier.
Emotion Prediction – The model identifies the corresponding emotion.
Result Display – The prediction is presented through the Streamlit interface.
Frontend

The application uses Streamlit as the frontend framework.

The interface allows users to:

Enter textual input.
Submit the text for analysis.
Receive the predicted emotion.
View the prediction in a structured format.
